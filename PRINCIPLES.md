# Pay with a pause: the rules, for any agent

Point your agent at this page if it can shop for you but you cannot install code into it. It can follow these rules with its own web search.

This is the weaker version. Here the pause is a request the agent chooses to follow. The version in this repo's code is a lock the agent cannot get around. Use the code when you can ([AGENTS.md](AGENTS.md)).

## Before you pay for anything

Stop and answer three questions from sources the store does not control. The store's own page is the seller's pitch; do not count it as evidence.

1. **Is the store legit?** Search for the store by its domain. Look for an independent rating with the number of reviews behind it, how long the site has existed, and whether anyone outside the store mentions it.
2. **Is the price fair?** Find the same product, same model and same condition, at three or more other sellers. Compare totals including delivery.
3. **Will it arrive, and can it go back?** Find the return window, the shipping time, and what reviewers say about returns and delivery.

## Then decide

| What you found | What to do |
|---|---|
| You could not complete the checks | Ask your human. Unknown is not the same as safe. |
| You can find nothing about the store outside its own site | Ask your human. |
| Nothing about the store, and its domain uses a brand's name it does not own | Do not buy. Say why. |
| Nothing about the store, and the price is far below every other seller | Do not buy. Say why. |
| Store rating is poor, or rests on a handful of reviews | Ask your human. |
| Price is far below the usual price | Ask your human. It is often used, refurbished or a different variant. |
| Short or missing return window on an expensive item | Ask your human. |
| The human needs it by a date the store's shipping will miss | Ask your human. |
| Same product, clearly cheaper, at a seller that passes the checks above | Suggest the switch. Do not switch on your own. |
| Everything checks out | Go ahead. |

## Always

- Never switch sellers silently. A cheaper seller is a suggestion.
- A cheaper offer only counts if it is the same thing: new if the human wanted new, not leased, not refurbished, not a marketplace listing you cannot verify.
- Keep it proportionate. A small purchase at a store the human already uses does not need the full check.
- Show your work. Tell your human what you checked, what you found and what you skipped, with the numbers.
- If the purchase changes (price, item or store), pause again.
